# 🔒 Bitcoin Portfolio & Tax Tracker (Local-First)

A privacy-focused, client-side web application to track your Bitcoin portfolio and prepare tax reports without compromising your financial data.

🌐 **Official Live Application:** [https://satoshitracker.de](https://satoshitracker.de)

---![SatoshiTracker Interface](https://github.com/user-attachments/assets/04e352ce-27f7-4870-bf1c-8e5ba32bcd2c)

## 🌟 Key Features

- **100% Privacy & Security:** All data remains exclusively on your local device (`localStorage`). No backend servers, no external databases, and no financial data leaks.
- **CSV Exchange Import:** Seamlessly import transaction histories from major exchanges (e.g. Kraken).
- **Real-Time Valuation:** Automated live price updates via public Bitcoin APIs.
- **Portfolio Analytics:** Instant calculations of total value, cost basis, and asset distribution.
- **Tax Reporting (In Progress):** Local calculation and generation of tax-relevant transaction logs.

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Architecture:** Local-First / Pure Client-Side Application
- **Deployment:** Web Hosting with SSL/HTTPS Domain Integration
- **Tooling:** Visual Studio Code & AI-assisted development workflows (Claude Code)
